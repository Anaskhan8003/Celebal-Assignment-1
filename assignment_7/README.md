# Laptop Price Predictor

This Streamlit web app predicts the price of a laptop based on various hardware configurations using a machine learning model.

# Project Overview

This project is part of the **Celebal Internship**. The goal is to develop a regression-based model to predict laptop prices using features like CPU, GPU, RAM, memory, and screen resolution. A user-friendly UI is built with Streamlit to interactively predict laptop prices.
